### 1. DeepSeek 发布 Super-agent 架构：AI 开始指挥 AI 干活
来源： AITNT（APPSO）/ GitHub | 日期： 11月1日
链接： [https://www.aitntnews.com/newDetail.html?newId=30790](https://www.aitntnews.com/newDetail.html?newId=30790) / [https://github.com/deepseek-ai/dsh-superagent-prototype](https://github.com/deepseek-ai/dsh-superagent-prototype)
摘要： DeepSeek Harness 团队发表《Super-agent 设计探索：迈向更自主的 Agent 系统》，提出 Router + Worker 双层架构：Router 持续接收群聊、GitHub、邮件等事件并分派任务，Worker 各自带独立上下文执行复现、评审、开发等任务，必要时再调 Subagent；并引入"投机执行"——没人 @ 它也能在后台静默复现 Bug 并提交修复 PR，只有确认有效才现身。关键数据：模拟 300 条消息流（约 20 条真实任务）的对照实验中，Super-agent 任务完成时间 p50 12.4 分钟、p95 15.7 分钟，传统单 Session 方案 p95 达 29.5 分钟；代价是缓存读取 Token 从 2323 万增至 3177 万（约 +37%）。异步 ReAct Loop 支持一边跑长任务一边接新指令，存算分离设计让电脑离线后任务可续跑，另有 Watchdog 监督员防死循环。影响分析：这是"AI 管理 AI"从论文走向工程实践的标志性一步——当人只能同时跟进 3-5 个 Session 时，Agent 的吞吐瓶颈已转移到人类注意力上；若该范式成立，未来人只负责定目标和验收，任务调度交给 AI 虚拟团队，但提示词注入、云端接管本地凭据等安全风险也随之放大。
