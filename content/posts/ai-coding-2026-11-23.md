## 🔥 今日头条

### 1. rust-anything：把整个应用重写成 Rust，并「证明」行为不变——一周 8k Star
**类型**：开源工具 | **热度**：⭐⭐⭐⭐⭐
**链接**：[github.com/erkamyaman/rust-anything](https://github.com/erkamyaman/rust-anything)
**核心亮点**：
- 三步工作流：`record` 用生成的边界用例录下原程序行为 → 编程 Agent 逐块写 Rust → 每一块都对照录制结果校验后才继续
- 2.0 版本交出实战成绩单：Prettier 的 Rust 移植 19 倍提速，15,861 / 17,224 次录制运行完全在 Rust 中执行、输出逐字节一致
- 提供 Claude Code 插件 + MCP Server，Trendshift 当日 Rust 榜第一，作者来自土耳其
**为什么火**：「用 Rust 重写」是程序员社区的老梗，rust-anything 把它变成了 Agent 可执行、可验证的工程流程，且不只翻译代码——它证明重写后的程序等价
**适用场景**：性能敏感的 CLI / HTTP 服务 / 库从 TypeScript、Python、C、Go、Ruby、Java 迁移到 Rust

## 🛠️ Agent 工具链

### 3. Claude Code 推出实验性 Code Mode：用一段 JavaScript 编排多个工具调用
**类型**：工具更新 | **推荐指数**：⭐⭐⭐⭐⭐
**链接**：[code.claude.com/docs/en/code-mode](https://code.claude.com/docs/en/code-mode)
**核心亮点**：
- Agent 不再「一次一个工具调用、读完结果再想下一步」，而是直接写一段 JavaScript，把查找、编辑、跑测试串成一步
- 天然支持并行调用、用上一个结果驱动下一个调用、只把需要的输出片段返回给模型——省轮次也省 token
- 适用场景官方明确：跨多文件的重复修改、需要过滤的搜索结果、可并行的独立命令
**注意**：实验特性默认关闭；需要 Claude Code v2.1.323+；代码超时 10 分钟；暂时不支持 Remote Control / 桌面 App 转会话

### 4. pansy：一个本地网关，让任何 Agent 用任何模型
**类型**：开源工具 | **推荐指数**：⭐⭐⭐⭐
**链接**：[github.com/pansy-ai/pansy](https://github.com/pansy-ai/pansy)
**核心亮点**：
- 「Claude Code 跑 Kimi、Codex 跑 DeepSeek、Gemini CLI 跑 GLM」——约 50 种 Agent 的模型配置一行切换，断开时精确还原配置
- 单网关翻译四种协议（Anthropic Messages / OpenAI Chat Completions / OpenAI Responses / Gemini），流式、工具调用、推理全兼容
- 多 Key 故障转移：额度耗尽或限流的 Key 自动「休息」，下一个顶上，Agent 看不到报错
**适用场景**：多模型混用、多 Key 轮换、想把 API 流量留在本地的团队

### 5. agent-crop：给 AI 编程助手一根「马鞭」——时间去哪了，用数据说话
**类型**：效率工具 | **推荐指数**：⭐⭐⭐⭐
**链接**：[github.com/oriliz/agent-crop](https://github.com/oriliz/agent-crop)
**核心亮点**：

**适用场景**：重度使用 Claude Code / DeepSeek Harness 的开发者做工作流复盘

### 6. trace2rules：从真实会话里挖出 AGENTS.md 规则
**类型**：开源工具 | **推荐指数**：⭐⭐⭐
**链接**：[github.com/rkkautsar/trace2rules](https://github.com/rkkautsar/trace2rules)
**核心亮点**：

## 🎯 本期 Prompt 技巧

### 「等价重写」验证咒语：让 AI 移植代码不失真
```markdown
# 移植/重写类任务的标准流程（rust-anything 的核心思想）
1. 先录行为，再动手：「先为原实现跑一批边界用例，保存输入输出快照」
2. 分块移植：「每次只移植一个函数/模块，移植完立即对照快照验证」
3. 逐字节对齐：「不接受『差不多』——输出必须与原实现完全一致，否则报告差异」
4. 可逆：「保留原实现，切换用开关控制，随时能回退」

# 示例
❌ 「把这个 Python 服务用 Rust 重写」
   → AI 一口气输出 2000 行，行为悄悄漂移

✅ 「先录制原服务 50 组真实请求的响应，然后只移植最慢的 3 个函数，
    每个移植完跑快照比对，全部一致后再继续」
   → 小步快跑，每步都有证据
```
