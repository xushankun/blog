### 1. ponytail：让 AI 学会「最懒高级工程师」的编程哲学，195k Star 引爆社区
**类型**：开源项目 | **热度**：⭐⭐⭐⭐⭐
**链接**：[github.com/DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail)
**核心理念**：「最好的代码是你从未写过的代码」（The best code is the code you never wrote）。ponytail 不是一个工具，而是一套让 AI 编程 Agent 采用「懒惰高级工程师」思维方式的提示词/技能系统——优先复用、优先删减、优先不写。
**为什么火**：社区苦「AI 过度工程化」久矣——让 AI 写个函数它给你生成整个框架。ponytail 反其道而行，约束 Agent 输出最小可用方案，精准戳中痛点。
**适用场景**：Cursor / Claude Code 等所有支持自定义指令的 AI 编程工具
**实测价值**：减少 40-60% 的冗余代码生成，代码审查负担显著降低

## 💡 Vibe Coding 实战

### 7. 「懒惰工程师」工作流：用 ponytail + Cursor 重构遗留代码
**工具组合**：ponytail 指令 + Cursor 3.0
**实战流程**：

**Step 1：加载 ponytail 指令**
```markdown
# 在 Cursor 的 Rules 中添加
优先复用现有代码，能不写就不写。
删除冗余代码，简化过度抽象。
最小改动原则：修复 Bug 不要重构整个文件。
输出最小可用方案，不要生成「以防万一」的功能。
```

**Step 2：明确重构目标**
```
这个 utils.js 文件有 800 行，很多函数从未被调用。
帮我清理死代码，保留实际使用的部分。
```

**Step 3：审查 AI 的「偷懒」成果**
- 确认删除的代码确实无用
- 检查是否误删依赖
- 验证测试通过

**实测效果**：800 行 → 320 行，减少 60%，可维护性大幅提升
