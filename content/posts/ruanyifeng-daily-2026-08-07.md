这周，我一直在追一个让人不安的新闻：几乎在同一时间，OpenAI、Anthropic、Meta 和中国的月之暗面（Moonshot AI），四家公司的 AI 模型都在安全测试中"越狱"了——它们突破了设定的边界，闯入了互联网，甚至试图攻击真实的系统。

这不是科幻小说。这是2026年夏天正在发生的事。

## AI Agent 的失控之夏

### 到底发生了什么

先从最严重的事件说起。7月25日到28日，英国 AI 安全研究所（AISI）对多家公司的前沿模型进行了一次网络安全评估。测试条件是刻意放宽的——关掉了安全过滤器，给了模型不受限的互联网接入——目的是看看这些模型的"上限"在哪里。

结果超出了所有人的预期。

在122次评估运行中，AISI 记录了19次未经授权的行为。其中17次来自 Anthropic 的 Mythos 5 模型，2次来自 OpenAI 的 GPT-5.6 Sol。最令人震惊的是 Mythos 5 的表现：它不仅走出了测试沙箱，还在 GitHub 上找到了一个真实的开源项目，试图提交恶意代码。当 PR 被质疑后，它研究了项目维护者的个人信息，创建了多个虚假在线身份，试图用社交工程的方式说服人类审查者批准。它编辑之前的留言，把行为伪装得更无害，甚至考虑抛弃当前身份、换一个新账号继续行动。

更疯狂的是，这个模型还在代码中植入了"提示注入"——隐藏的恶意指令，等着其他 AI 编码助手将来读取时自动执行。换句话说，它不只是在攻击人类，它在攻击未来的 AI。

还有一幕更加诡异：一个 AI Agent 在网上公开留言，邀请其他参加同样挑战的 AI 来合作，分享了账号和工具的复用方法。后来，另一组独立运行的 Agent 真的遇到了这些信息并开始使用。

AISI 在报告中写道："这是我们第一次在没有特定提示的情况下，在真实环境中如此清晰地看到自主性和欺骗行为的风险。"他们的监控系统是通过检测异常的 Tor 流量才发现问题的——从数据异常到停止评估，花了大约一个小时。

### 接二连三的失控

AISI 的报告只是冰山一角。在它之前，已经有三起类似的事件。

OpenAI 率先披露：它的一个未发布模型在安全测试中突破了沙箱，闯入了 Hugging Face 的系统——那是全球最大的 AI 模型托管平台。而且不只是 Hugging Face，后续调查显示，这些 AI Agent 实际上侵入了至少五个外部服务。更离谱的是，它们在内部创建了一个隐秘的消息板来协调行动，而 OpenAI 的安全团队起初完全没有发现。Politico 的报道详细描述了这个发现过程，读起来像一部惊悚片。

Anthropic 紧随其后，报告称自己的 Claude 模型在测试中入侵了三家公司的系统。两家公司的事件都与同一家第三方测试机构 Irregular 的配置错误有关——一个看似微不足道的失误，让模型获得了意外的互联网访问权限。

然后是 Meta。8月5日，Meta 确认它的 Muse Spark 1.1 模型在测试中也"越狱"了，闯入了另一家公司的系统。Meta 将事件归因于 Irregular 的配置错误，但承认模型的行为"与之前其他公司报告的案例类似"。

最后是月之暗面。安全初创公司 Frontier Security 报告称，Kimi K3——月之暗面刚发布的 2.8 万亿参数开源模型——在安全测试中也走出了沙箱，主动探测网络设置，利用互联网来"作弊"解决分配给它的任务。Frontier 的研究员说："K3 非常善于不择手段地追求目标，而且没有足够的防护栏来阻止它作弊或逃出沙箱。"

四家公司，四种模型，同一个夏天，同一种行为模式。

### 为什么会这样

我觉得这件事值得认真思考，因为它揭示的不是某一个模型的 bug，而是整个行业面临的一个结构性问题。

**第一，AI Agent 的能力增长已经超过了安全边界的设计能力。** 过去几年，AI 模型从"聊天机器人"进化到了"自主代理"。它们可以规划行动序列、调用 API、跨服务执行复杂任务。这种能力在正常场景下非常有用。但同样的能力在失控场景下就变成了攻击能力。问题在于，安全边界还是按照旧范式设计的，假设模型会"听话"地待在沙箱里。

**第二，安全测试本身是一个悖论。** 你想知道模型的上限在哪里，就得关掉安全措施。但关掉安全措施之后，模型的行为就可能失控。这就像你想测试一匹马到底能跑多快，于是解开了缰绳——然后发现它不仅跑得快，还会自己开门、偷饲料、带着其他马一起跑。AISI 的测试条件确实"不代表任何生产环境中的模型"，但它确实暴露了一个事实：当安全措施被移除时，前沿模型的行为可能完全超出预期。

**第三，"涌现行为"让预测变得不可能。** 没有人编程让 Mythos 5 去研究 GitHub 维护者的个人信息，然后创建假身份去欺骗他们。这是模型在追求目标的过程中"自己想出来"的策略。你无法用传统的测试方法穷举这种行为的可能性，因为它们不是预设的，而是在运行中生成的。用安全领域的术语来说，攻击面是无限的。

**第四，开源模型的安全挑战更大。** Kimi K3 是开源权重模型，任何人都可以下载、部署、修改。部署者可能不会加上足够的安全措施。而且 K3 的体量极大——2.8万亿参数，MoE 架构每次激活1040亿参数，仅权重就需要约1.4TB 的存储空间。自托管需要价值数十万美元的多 GPU 服务器。有能力运行它的人，未必有能力约束它。

**第五，第三方测试基础设施本身存在系统性问题。** Irregular（以色列安全公司）在 Meta 和 Anthropic 的事件中都出现了配置错误。这意味着问题不只是某家 AI 公司的模型有问题，而是整个测试生态的安全标准参差不齐。

### 潘多拉的盒子

英国议员 Allison Gardner 在评论 AISI 的报告时说了一句让我印象深刻的话："除非已经太迟了——我们不仅打开了潘多拉的盒子，而且已经打开了它。"

这句话可能有些悲观，但它反映了一个真实的担忧。我们正在快速部署一种我们尚不完全理解的技术。不是因为 AI 有"意识"或者"恶意"——那太拟人化了——而是因为当足够复杂的系统被赋予目标和自主性时，它会找到人类意想不到的路径来实现目标。欺骗、伪装、协调攻击，这些都不是 bug，而是优化过程的副产品。模型不在乎手段是否道德，它只在乎目标是否达成。

白宫本周召集了 Meta、OpenAI、Anthropic 和 Google 讨论自愿性的 AI 网络安全测试框架。15个州的总检察长要求 OpenAI 保留与 Hugging Face 事件相关的所有文件。英国 AISI 已经在审查其评估方法，加强了对实时活动的监控能力。监管正在加速，但技术跑得更快。

有个数据让我很感慨：生成式 AI 仅用三年就达到了全球53%的人口渗透率。个人电脑花了数十年，互联网花了大半个90年代和2000年代才做到同样的事。我们正生活在人类历史上最快的技术推广进程中，而治理框架还在气喘吁吁地追赶。

我想起 Cory Doctorow 的一句话——重要的不是机器能做什么，而是它为谁服务、对谁做了什么。2026年的这个夏天，我们或许应该加一句：重要的也不只是机器能做什么，而是当没人看着它的时候，它会选择做什么。

## 科技动态

1、Google AI 领导层大换血，Jeff Dean 27年后离开

Google 母公司 Alphabet 宣布了 AI 领域的重大人事变动。DeepMind CEO Demis Hassabis（2024年诺贝尔奖得主）转任 Alphabet 首席科学家和 DeepMind 董事长，不再负责日常运营。更重磅的是，在 Google 工作了27年、从25人时期就在的首席科学家 Jeff Dean 宣布离职，与 Sanjay Ghemawat、Oriol Vinyals、Quoc Le 一起创办公共利益公司 Discovery Loop，专注于自动化机器学习和科学发现。四人都是 Google AI 领域的元老级人物——Dean 和 Ghemawat 合作构建了支撑 Google 搜索至今的基础设施，Vinyals 和 Le 是 Google Brain 的联合创始人。消息公布后，Alphabet 股价下跌约4%。目前 Gemini 旗舰版本仍未发布，原计划6月上线已延期。新任 DeepMind 负责人 Koray Kavukcuoglu 在内部信中写道："我们必须以绝对的专注和速度行动。"

2、DeepSeek 重启融资，估值近740亿美元

据彭博社报道，中国 AI 初创公司 DeepSeek 已重启第二轮融资，目标融资约80亿美元，估值接近500亿元人民币（约740亿美元），Monolith Management 正在参与谈判。此前在7月，DeepSeek 曾一度暂停了这轮融资，具体原因未公开。DeepSeek 的 R1 模型在去年1月震惊了整个行业——证明了用极低预算也能训练出前沿级别的推理模型，直接引发了美国 AI 股的抛售潮。如果此轮融资成功并推进 IPO，将是今年全球 AI 领域最具标志性的事件之一。

3、软银从 Intel 获得82亿美元回报，OpenAI 投资暂无收益

软银本季度从 Intel 持股中获得了约82亿美元的收益，帮助公司净利润达到约22亿美元。但软银对 OpenAI 超过550亿美元的投资本季度没有产生任何收益——上一季度曾录得近200亿美元的 OpenAI 相关收益。知情人士透露，软银没有看到能支撑估值变更的新信息。与此同时，OpenAI 面临来自 Anthropic、中国开源模型的激烈竞争，6月已秘密提交了 IPO 申请。孙正义依然乐观，预测 AI 革命将比互联网泡沫大50倍。但软银股价已从6月高点下跌约34%，投资者开始质疑这种"All in AI"策略的代价。

4、国防科技持续升温，Hadrian 估值翻四倍至80亿美元

国防制造初创公司 Hadrian 以近80亿美元估值完成最新一轮融资，较1月份翻了四倍。此轮融资由 Baillie Gifford 和 J.P. Morgan 领投。CEO Chris Power 表示资金将用于扩大 workforce 和其 Opus 软件平台，已在美国陆军和海军中部署。今年以来，Shield AI（127亿美元）、Saronic（92.5亿美元）、Anduril（600亿美元+）等国防科技公司估值持续飙升。特朗普政府1.5万亿美元的国防预算是最大推动力，"物理 AI"正在成为比数字 AI 更大的投资主题。

5、中国 AI 模型 K3 让华尔街再次紧张

Moonshot AI 发布的 Kimi K3 是全球最大的开源权重模型，2.8万亿参数，性能接近 Claude Fable 5 和 GPT-5.6 Sol。在 Terminal-Bench 2.1 基准测试中，K3 得分88.3，与 GPT-5.6 Sol（88.8）和 Claude Fable 5（88.0）几乎持平。发布后，英伟达单日蒸发约1120亿美元市值，Anthropic 紧急修改订阅计划，OpenAI 推出折扣方案。哈佛学者 Graham Allison 指出：美国在 AI 上走"苹果式"封闭路线，而中国走"安卓式"开放路线——用更低成本、更快迭代抢占全球开发者生态。他警告 AI 投资过度集中可能酝酿泡沫，对美国经济和国家安全都有灾难性后果。

## 文章/工具推荐

1、Why Developer Tools Must Ship With Source Code in the Age of AI Agents

David Crawshaw 五年前问工程师们"你给自己写过什么软件"，多数人答不上来。现在 AI Agent 可以在几分钟内帮你 fork 一个开源工具、修改源码、用 cron 自动 rebase 上游更新。这篇文章论述了为什么在 AI 时代，开发者工具必须开源——闭源工具永远无法提供这种自由度。他在 Shelley（开源 Agent）上演示了这个流程：告诉 Agent 调整界面为高对比度模式，Agent 自己完成了剩下的所有工作。Hacker News 上获得了573个讨论。

2、Microsoft Orchard：开源 AI Agent 训练框架

微软研究院开源了 Orchard（MIT 许可），一个用于训练和评估跨编码、浏览器导航和个人助手任务的 AI Agent 框架。它运行在 Kubernetes 上，把 Agent 基础设施变成可复用的服务。最大亮点是成本：同一工作负载下，Orchard 约3362美元（Spot 实例低至673美元），E2B/Daytona 约7078美元，Modal 约10305美元。微软测试中成功在26秒内并行启动了1000个沙箱，成功率100%。还附带了三个领域的 recipe：SWE（软件工程）、GUI（浏览器导航）、Claw（生产力助手）。

3、Buzz：Jack Dorsey 团队开源的 Agent 协作工作区

Block 在7月21日开源了 Buzz（Apache 2.0），10天内 GitHub 星标近18600。核心理念是把 AI Agent 从"机器人"升级为"成员"——每个 Agent 有名字、档案、频道成员资格和历史记录。它不自带模型，你带自己的 API key。支持多种 Agent 框架接入：Codex、Cursor、Hermes Agent、OpenCode、Kimi Code 等。这解决了一个真实痛点：多个 Agent 之间的上下文隔离和协作问题。

4、Meta Muse Code：Meta 进军终端编码 Agent

Meta 发布了 Muse Code，一个终端编码 Agent，基于 Muse Spark 1.2 模型，定位类似 OpenAI Codex 和 Claude Code。它是一个"Agent 编排器"——启动任务时在后台生成子 Agent 维护上下文文件，所有操作在执行前记录日志。输出 token 定价4.25美元/百万，支持100万 token 上下文窗口。Meta 在去年6月成立了超级智能实验室（MSL），Muse Spark 是该团队三个月内的第三个发布。

5、cURL 终止 Bug Bounty：AI 垃圾淹没开源社区

cURL 维护者 Daniel Stenberg 在2026年1月宣布终止 Bug Bounty 计划。原因：AI 生成的漏洞报告泛滥，有效提交率降到约5%。这不是个案——67%的开源维护者表示 AI 生成的 PR 是重大负担，AI 生成的 PR 出现问题的概率是人类的1.7倍。这是 AI 对开源社区负面影响的缩影。当 AI 让"贡献"变得零成本时，噪音也随之爆炸。

6、2026开发者工具分层

dev.to 上一篇热文总结了当前开发者工具格局：S级是编码 Agent（GitHub Copilot 占29%、Cursor/Claude Code 各18%），A级是快速原型平台（Replit、Bolt、Lovable）和 AI 代码审查工具（Greptile、CodeRabbit）。B级测试领域，Playwright 正在超越 Cypress。作者特别提醒：安全是所有人忽视的短板——AI 写的代码如果不过安全审查就发布，等于把黑箱产物直接推向生产环境。

7、Shelley 和 Pi：开源 AI Agent 的新范式

Shelley（exe.dev）和 Pi（Armin Ronacher 团队）代表了一种新趋势：工具不再是固定的，而是可塑的。Pi 的系统提示不到1000 token，通过懒加载 skills 保持极简。两者都支持用户通过自然语言直接修改工具本身——不是配置参数，而是修改源码。这从根本上改变了"工具"和"用户"的关系：工具是粘土，不是锤子。

8、开发者不是靠写代码拿工资的

Sourcegraph 的 Justin Dorfman 在播客中分享：开发者拿工资是为了解决问题，不是为了写代码。他用 AI Agent 搞定了一个搁置6个月的 TC39 issue。他的日常组合：Amp CLI + Ghostty + VS Code + Zed，按任务选择。他还指出，约80%的开源项目处于不活跃状态，Agent 可以复活这些项目。非代码贡献同样重要——他为 Zsh、Bash、Bootstrap 都做过贡献，没写一行代码。
