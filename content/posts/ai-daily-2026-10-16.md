今天是"开放"的一天：Meta 拿出 816B 参数的开放权重模型 Muse Spark Open，Claude Opus 5.5 极速模式全面解禁取消等待名单，NVIDIA 也开源了新的多模态模型。开放权重、开放速度、开放生态——各家都在用"降低门槛"抢开发者。

## 头条一：Meta 发布 Muse Spark Open，816B 开放权重模型

Meta AI 今日发布 Muse Spark Open，称其为迄今能力最强的美国开放权重模型。该模型面向编程与 Agent 任务，擅长长时程任务、复杂软件工程与多步推理。关键规格：总参数 816B，激活参数 42B，支持 1M token 上下文，具备原生多模态能力。

同日 Meta 发布了模型许可协议：授予被许可方免费使用、修改、蒸馏、分发乃至销售的权利，仅需显著标注 "Built with Muse Spark Open"；若通过 API 向第三方提供访问且连续 12 个月营收超 2000 万美元，则需另行签署协议。得益于与 Apple 的合作，模型在新款 Mac Studios 上运行良好；TokenSpeed 已实现 Day-0 支持，在 NVIDIA B300 上实现每用户 190 tokens/s 的输出速度。开放权重模型的竞争，正在从"能不能用"转向"协议划多大边界"。

## 头条二：Claude Opus 5.5 极速版全面解禁，提速 2.5 倍还降价

Anthropic 宣布 Claude Opus 5.5 的「极速模式」彻底结束研究预览阶段，取消所有等待名单，向全体开发者开放。重点是：不降智、不阉割——采用与标准版完全相同的模型权重与智力水平，纯粹通过优化底层 API 和推理配置，把资源集中在响应速度上，OTPS 最高提升 2.5 倍。

用法简单粗暴：API 请求里加 `speed: "fast"` 即可，Claude Code 用户敲 `/fast` 随时切换。价格反而更低：Opus 5.5 极速模式输入 $8/百万 Token、输出 $40/百万 Token，比 Opus 5/4.8 极速模式的 $10/$50 更便宜。注意几个坑：极速模式有独立限流（触顶自动回退标准速度）、与标准模式不共享 Prompt Cache（建议会话一开始就开启），订阅用户走"使用额度"计费、不含在常规订阅额内。企业侧可配 `fastModePerSessionOptIn` 强制按会话手动开启，防止员工并发跑任务把额度烧穿。另外 Claude 近期上线的「空闲压缩」也值得一试：长会话闲置约 54 分钟后自动压缩成摘要，回来只读摘要就能续上思路。有评论一语中的："对于 Agent 循环来说，p95 延迟比什么都重要。"

## 头条三：NVIDIA 开源 Nemotron 3.5 Super VL 多模态模型

NVIDIA 发布开源模型 Nemotron 3.5 Super VL，将推理与工具调用能力同文本、图像、文档和视频理解相结合，面向长时间运行的 AI 智能体场景。总参数 120B、每 token 激活 12B，支持最高 1M token 上下文窗口，权重已在 Hugging Face 上提供。

120B 总参数配合 12B 激活的设计，在保持推理能力的同时兼顾运行效率，Nemotron 系列已成为企业级 AI 应用的重要选择。

## 头条四：Meta 超级智能实验室 Muse Wonder 上线 Cursor

Cursor 官方宣布，来自 Meta Superintelligence Labs 的 Muse Wonder 模型现已上线。该模型在默认 effort 设置下于 CursorBench 评测中得分 46.1%，为所有 Muse 模型中的最高分。定价：输入 $4/百万 token，输出 $20/百万 token。

Muse 系列在编程场景持续发力，46.1% 的 CursorBench 得分显示其在复杂软件工程任务上的实力。结合今天 Muse Spark Open 的发布，Meta 在"开放权重 + 编程 Agent"这条线上的布局已经很完整了。

## 头条五：Anthropic 承诺 500 万美元资助数学领域 AI 研究

Anthropic 表示，如何在数学研究乃至更广泛的科学研究中用好 AI，需要投入时间、精力和资源，已承诺 500 万美元支持数学家推动科学进步。此外，通过与 OpenAI 的新合作，将投入 1500 万美元用于工作坊和倡议，并为基金会支持的研究人员提供免费 AI 计算资源。
